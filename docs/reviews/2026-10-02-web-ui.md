# Review: embedded web UI (PR #4)

Cross-vendor review of `feat/web-ui` @ 15001b5. Verdict: **APPROVED WITH FIXES**.

## Scope checked
Auth and identity, CSRF, XSS, version conflicts, SSE lifecycle, in-process daemon access, backward compatibility, tests.

## Findings

| # | Severity | Finding | Disposition |
|---|----------|---------|-------------|
| 1 | MEDIUM | With `allow_local_writes = true`, a DNS-rebinding page is same-origin with its own hostname, so the `Origin`/`Sec-Fetch-Site` checks pass and it could edit the plan through the loopback peer. | **Fixed**: the local exception now also requires a loopback `Host` (`localhost`, `127.x`, `::1`). Test `TestLocalWritesRefuseRebindingHost`. README updated. |
| 2 | LOW | `allow_local_writes` combined with a proxy that forwards unauthenticated requests grants owner writes to the proxy's users. | Documented in README (never enable behind a proxy). |
| 3 | LOW | `horch web --listen 0.0.0.0:...` is accepted silently (reads become network-visible; writes stay refused for non-loopback peers). | Deferred: consider a startup warning. |
| 4 | LOW | No cap on concurrent SSE clients; each holds a daemon socket and polls `web.activity` under the engine lock every 5s. | Deferred. |
| 5 | LOW | No read/write deadline on non-SSE request bodies/responses beyond header timeout and 32 KiB body cap. | Deferred. |

## Verified, no change needed
- Default bind is `127.0.0.1:7171`; README says to keep it on loopback behind the proxy and to strip the incoming identity header.
- Writes require the configured header (exactly one value, from a loopback peer) to equal the owner, or the explicit local opt-in. A non-loopback peer sending the header is refused (tested).
- Write endpoints are POST only; JSON content type, `Origin` host match and `Sec-Fetch-Site` are enforced; unknown fields and trailing data are rejected; the body JSON principal is overridden by the authenticated one. No state-changing GET.
- All plan/inbox/worker text goes through `esc()` before `innerHTML`; CSP forbids inline script and external origins.
- `if_version` and `if_plan_version` are required (add excludes `if_version`); stale edits return 409 and the UI refreshes without retrying. The new plan-version fence in `plan.item.*` only applies when the field is non-zero.
- SSE: the handler context cancels the stream goroutine and closes its daemon connection; replay via `Last-Event-ID`/`since`; per-write deadlines; the browser reconnects on `unavailable`.
- The daemon is accessed through the in-process socket client; there is no shelling out.
- Backward compatibility: only additive (new `web.activity` op, `[web]` config, `horch web`); existing commands and wire formats are unchanged.
